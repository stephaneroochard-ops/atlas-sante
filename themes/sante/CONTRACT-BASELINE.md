# Base contractuelle restaurée

Le thème est reconstruit dans `themes/sante/` comme source HTML statique destinée à une conversion Astro mécanique. La pile du thème est limitée à Tailwind CSS v4, `@fontsource/inter` et `@fontsource/cairo`.

Les règles non négociables de cette reconstruction sont les suivantes : aucun framework front, aucun chemin `/manus-storage/`, aucune propriété ou classe directionnelle physique, `lang="ar" dir="rtl"` sur les pages arabes et des données remplaçables marquées par `data-field`.
